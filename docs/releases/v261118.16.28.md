## 更新内容

- **外观主题化**：配色、质感、字号与预设可调，新增额度环与会话排序；深浅两套主题一致。
- **剪贴板增强**：历史上限提到 500 条，岛内可直接查看行数，支持多选删除，全选不再包含收藏项，图片支持原图预览。
- **贴边与窗口行为**：新增「Agent 运行中 / 显示歌词 / 待办计时」三种不贴边开关（默认全关）；切换贴边样式即时演示 2.5 秒；全屏检测改用矩形覆盖加系统状态兜底；窗口显式不进 Alt+Tab。
- **更新与身份**：代理识别兼容 socks5；下载镜像回退只换下载地址、签名校验不符即中止；关于页加入更新控件与红点，收起岛显示更新红点；清理残留的 fly-island 旧名。
- **消息、音乐、通知与杂项**：QQ 通知停留时长可调；QQ 按会话真正清空消息；插件失败给出具体原因；清理品牌残留并支持导出目录旧名回退；收起态默认封面。
- **用量不再被代理挡住**：本地 Magpie 网关改为直连，不再走系统代理。此前若本机开着系统代理，用量与额度块会因为网关请求被代理拦成 502 而整块隐藏；现在无论系统代理是否开启都能正常显示。

## What's new

- **Themes and appearance**: adjustable colors, texture, font sizes and presets, plus a quota ring and session sorting; the light and dark themes stay consistent.
- **Clipboard enhancements**: history limit raised to 500 items, line count shown on the island, multi-select delete, select-all no longer includes favorites, and images can be previewed at full size.
- **Tucking and window behavior**: three new "don't tuck while" switches (agent running / lyrics shown / todo timer, all off by default); a 2.5-second preview when switching tuck styles; full-screen detection via rectangle coverage plus a system-state fallback; the window is now excluded from Alt+Tab.
- **Updater and identity**: socks5 proxy strings are recognized; download mirror fallback only swaps the URL and aborts if the signature check fails; About gained an update control and badge, and the collapsed island shows an update dot; leftover fly-island naming cleaned up.
- **Messages, music, notifications and misc**: configurable QQ notification duration; per-conversation clearing of QQ messages; concrete reasons when a plugin fails; brand leftovers cleaned up with export-folder fallback for the old name; a default cover art for the collapsed island.
- **Usage no longer blocked by proxy**: the local Magpie gateway is now reached directly instead of through the system proxy. Previously, with a system proxy enabled, the gateway request was intercepted and returned 502, hiding the whole usage/quota block; it now shows correctly whether or not a system proxy is on.
