## 更新内容

- **产品内自愈守护，不再依赖外部计划任务**：浮岛现在内置双进程守护。主进程崩溃或被强制结束时，内置守护进程会在约 1 秒内自动把主进程拉起、恢复本地服务端口，不会重复拉起多个实例。此前依赖的外部 Windows 计划任务和守护脚本已退役，不再往系统里安装计划任务。
- **自愈开关**：设置页新增「崩溃自愈守护」开关（中英文），不想让浮岛自动重拉时可以直接关闭。主动退出浮岛仍然不会被拉回，这一点保持不变。
- **稳定性与回归**：全量回归通过——前端 416 项测试全绿、Rust 406 项测试通过、clippy 零告警。

## What's new

- **Self-healing guard built in, no external scheduled task**: FloatIsle now ships with a two-process guard. If the main process crashes or is force-terminated, the built-in guardian relaunches it within about a second and restores the local service ports, without spawning duplicate instances. The external Windows scheduled task and guard script used before have been retired; FloatIsle no longer installs a scheduled task into the system.
- **Self-healing switch**: a new "Crash self-healing guard" switch in Settings (available in both Chinese and English) lets you turn automatic relaunching off. Deliberately quitting FloatIsle still never triggers a relaunch, as before.
- **Stability and regression**: full regression passed — 416 front-end tests green, 406 Rust tests passed, zero clippy warnings.
